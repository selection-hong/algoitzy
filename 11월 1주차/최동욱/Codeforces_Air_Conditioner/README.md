## [Air Conditioner 문제 링크](https://codeforces.com/problemset/problem/1304/C)

# C. Air Conditioner

- 난이도: 1500
- 시간 제한: 1초
- 메모리 제한: 256MB

## 문제 설명

길동이는 불고기 식당을 운영하고 있다. 식당에는 손님이 많아서 많은 손님이 방문하기 전에 예약하는 것을 좋아한다.

길동이는 손님들을 만족시키기 위해 매우 노력하며, 심지어 모든 손님이 선호하는 온도 범위까지 외웠다!

예약 목록을 살펴보던 길동이는 식당의 온도를 조절하여 모든 손님을 만족시키고 싶어 한다.

식당에는 **꺼짐, 난방, 냉방**의 세 가지 상태를 가진 에어컨이 있다.

- **꺼짐:** 식당의 온도가 그대로 유지된다.
- **난방:** 1분마다 온도가 1도 상승한다.
- **냉방:** 1분마다 온도가 1도 하강한다.

길동이는 정수로 표현되는 임의의 시각에 에어컨의 상태를 원하는 만큼 변경할 수 있다.

에어컨은 처음에 꺼져 있다.

각 손님은 다음 세 가지 값으로 나타낸다.

- `t[i]`: `i`번째 손님이 식당을 방문하는 시간(분)
- `l[i]`: 해당 손님이 선호하는 온도 범위의 최솟값
- `h[i]`: 해당 손님이 선호하는 온도 범위의 최댓값

손님이 식당을 방문하는 순간의 온도가 선호하는 온도 범위 안에 있다면, 해당 손님은 만족한다.

정확히 말하면, `i`번째 손님은 `t[i]`분에 식당의 온도가 `l[i]` 이상 `h[i]` 이하일 때, 그리고 그때에만 만족한다.

식당의 초기 온도, 예약한 손님들의 방문 시간과 선호 온도 범위가 주어진다.

당신의 임무는 **모든 손님을 만족시키는 것이 가능한지** 판별하여 길동이를 도와주는 것이다.

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `q`가 주어진다.

- `1 ≤ q ≤ 500`

이어서 각 테스트 케이스에 대한 설명이 주어진다.

각 테스트 케이스는 다음과 같이 구성된다.

- 첫 번째 줄에는 두 정수 `n`, `m`이 주어진다.
  - `1 ≤ n ≤ 100`
  - `-10⁹ ≤ m ≤ 10⁹`
  - `n`: 예약한 손님의 수
  - `m`: 식당의 초기 온도
- 다음 `n`개의 줄에는 각각 세 정수 `t[i]`, `l[i]`, `h[i]`가 주어진다.
  - `1 ≤ t[i] ≤ 10⁹`
  - `-10⁹ ≤ l[i] ≤ h[i] ≤ 10⁹`
  - `t[i]`: `i`번째 손님의 방문 시간
  - `l[i]`: 선호 온도 범위의 최솟값
  - `h[i]`: 선호 온도 범위의 최댓값

선호 온도 범위에는 양 끝값이 포함된다.

손님들은 방문 시간이 감소하지 않는 순서로 주어지며, 현재 시각은 `0`이다.

## 출력

각 테스트 케이스마다 한 줄에 결과를 출력한다.

- 모든 손님을 만족시킬 수 있다면 `"YES"`를 출력한다.
- 그렇지 않다면 `"NO"`를 출력한다.

각 문자는 대문자 또는 소문자로 출력해도 된다.

## 예제 설명

첫 번째 테스트 케이스에서 길동이는 다음과 같이 에어컨을 조절하여 모든 손님을 만족시킬 수 있다.

- **0분:** 에어컨을 난방 상태로 변경한다. (온도는 0도)
- **2분:** 에어컨을 꺼짐 상태로 변경한다. (온도는 2도)
- **5분:** 에어컨을 난방 상태로 변경한다. (온도는 2도이며, 첫 번째 손님이 만족한다.)
- **6분:** 에어컨을 꺼짐 상태로 변경한다. (온도는 3도)
- **7분:** 에어컨을 냉방 상태로 변경한다. (온도는 3도이며, 두 번째 손님이 만족한다.)
- **10분:** 온도가 0도가 되어 마지막 손님을 만족시킨다.

세 번째 테스트 케이스에서 길동이는 0분에 에어컨을 난방 상태로 변경한 뒤, 그 상태를 계속 유지하면 된다.

그러면 모든 손님을 만족시킬 수 있다.

첫 번째 손님과 두 번째 손님의 방문 시간이 같다는 점에 유의하라.

두 번째와 네 번째 테스트 케이스에서는 적어도 한 명의 손님을 만족시키지 못한다.
