## [Selling a Menagerie 문제 링크](https://codeforces.com/problemset/problem/1872/F?utm_source=chatgpt.com)

# F. Selling a Menagerie

- 난이도: 1800
- 시간 제한: 2초
- 메모리 제한: 256MB

## 문제 설명

당신은 `1`부터 `n`까지 번호가 매겨진 `n`마리의 동물로 이루어진 동물원의 주인이다.

하지만 동물원을 유지하는 데 상당한 비용이 들기 때문에, 동물들을 팔기로 결정했다!

각 동물은 정확히 하나의 다른 동물을 두려워한다는 사실이 알려져 있다.

더 정확히 말하면, 동물 `i`는 동물 `a[i]`를 두려워한다 (`a[i] ≠ i`).

또한 각 동물의 가격도 알려져 있으며, 동물 `i`의 가격은 `c[i]`이다.

당신은 모든 동물을 정해진 순서대로 판매할 것이다.

형식적으로, 순열† `p1, p2, ..., pn`을 하나 선택하고, 동물 `p1`을 먼저 판매한 다음 동물 `p2`를 판매하는 식으로 진행하여, 마지막으로 동물 `pn`을 판매해야 한다.

동물 `i`를 판매할 때 다음 두 가지 경우가 발생할 수 있다.

- 동물 `a[i]`가 동물 `i`보다 먼저 판매되었다면, 동물 `i`를 판매하여 `c[i]`만큼의 돈을 받는다.
- 동물 `a[i]`가 동물 `i`보다 먼저 판매되지 않았다면, 동물 `i`를 판매하여 `2 × c[i]`만큼의 돈을 받는다. (놀랍게도 현재 두려움을 느끼고 있는 동물이 더 가치가 높다.)

당신의 임무는 총수익을 최대화할 수 있도록 동물들의 판매 순서를 결정하는 것이다.

예를 들어, `a = [3, 4, 4, 1, 3]`, `c = [3, 4, 5, 6, 7]`이고, 선택한 순열이 `[4, 2, 5, 1, 3]`이라면 다음과 같다.

- 첫 번째로 판매하는 동물은 동물 `4`이다. 동물 `a[4] = 1`은 아직 판매되지 않았으므로, 동물 `4`를 판매하여 `2 × c[4] = 12`만큼의 돈을 받는다.
- 두 번째로 판매하는 동물은 동물 `2`이다. 동물 `a[2] = 4`는 이미 판매되었으므로, 동물 `2`를 판매하여 `c[2] = 4`만큼의 돈을 받는다.
- 세 번째로 판매하는 동물은 동물 `5`이다. 동물 `a[5] = 3`은 아직 판매되지 않았으므로, 동물 `5`를 판매하여 `2 × c[5] = 14`만큼의 돈을 받는다.
- 네 번째로 판매하는 동물은 동물 `1`이다. 동물 `a[1] = 3`은 아직 판매되지 않았으므로, 동물 `1`을 판매하여 `2 × c[1] = 6`만큼의 돈을 받는다.
- 다섯 번째로 판매하는 동물은 동물 `3`이다. 동물 `a[3] = 4`는 이미 판매되었으므로, 동물 `3`을 판매하여 `c[3] = 5`만큼의 돈을 받는다.

이 순열을 선택했을 때 총수익은 `12 + 4 + 14 + 6 + 5 = 41`이다.

이 예제에서 `41`은 가능한 최대 수익이 아니라는 점에 유의하라.

† 길이가 `n`인 순열은 `1`부터 `n`까지의 서로 다른 정수 `n`개로 이루어진 배열이다.

예를 들어 `[2, 3, 1, 5, 4]`는 순열이지만, `[1, 2, 2]`는 순열이 아니다 (`2`가 배열에 두 번 등장한다).

또한 `[1, 3, 4]`도 순열이 아니다 (`n = 3`이지만 배열에 `4`가 존재한다).

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어진다.

\- `1 ≤ t ≤ 10⁴`

이어서 각 테스트 케이스에 대한 설명이 주어진다.

각 테스트 케이스는 다음과 같이 구성된다.

- 첫 번째 줄에는 정수 `n`이 주어진다.
  - `2 ≤ n ≤ 10⁵`
  - `n`: 동물의 수
- 두 번째 줄에는 `n`개의 정수 `a1, a2, ..., an`이 주어진다.
  - `1 ≤ a[i] ≤ n`
  - `a[i] ≠ i`
  - `a[i]`: 동물 `i`가 두려워하는 동물의 번호를 의미한다.
- 세 번째 줄에는 `n`개의 정수 `c1, c2, ..., cn`이 주어진다.
  - `1 ≤ c[i] ≤ 10⁹`
  - `c[i]`: 동물 `i`의 가격을 의미한다.

모든 테스트 케이스에 대한 `n`의 합은 `10⁵`을 초과하지 않는다.

## 출력

각 테스트 케이스마다 한 줄에 `n`개의 정수를 출력한다.

\- 정답은 순열 `p1, p2, ..., pn`이어야 하며, 총수익을 최대화하기 위해 동물들을 판매해야 하는 순서를 나타낸다.

가능한 정답이 여러 개라면, 그중 아무거나 출력해도 된다.
