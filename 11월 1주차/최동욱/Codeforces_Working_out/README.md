## [Working out 문제 링크](https://codeforces.com/problemset/problem/429/B?utm_source=chatgpt.com)

# B. Working out

- 난이도: 1600
- 시간 제한: 2초
- 메모리 제한: 256MB

## 문제 설명

여름이 다가오고 있다!

Iahub와 Iahubina는 해변에서 멋진 모습을 보여주고 싶어 운동을 시작하기로 했다.

두 사람이 이용하는 체육관은 `n`개의 행과 `m`개의 열로 이루어진 격자 `a` 형태이다.

각 칸 `a[i][j]`는 `i`번째 행, `j`번째 열에서 운동했을 때 소모하는 칼로리를 나타낸다.

Iahub는 `a[1][1]`에서 운동을 시작하여 `a[n][m]`에서 운동을 마쳐야 한다.

Iahub는 현재 칸 `a[i][j]`에서 운동을 마친 후 다음 두 칸 중 하나로 이동할 수 있다.

- `a[i+1][j]`: 아래쪽 칸
- `a[i][j+1]`: 오른쪽 칸

마찬가지로 Iahubina는 `a[n][1]`에서 운동을 시작하여 `a[1][m]`에서 운동을 마쳐야 한다.

Iahubina는 현재 칸 `a[i][j]`에서 운동을 마친 후 다음 두 칸 중 하나로 이동할 수 있다.

- `a[i][j+1]`: 오른쪽 칸
- `a[i-1][j]`: 위쪽 칸

두 사람의 운동에는 한 가지 추가 조건이 있다.

두 사람은 체육관의 정확히 한 칸에서 만나야 한다.

그 칸에서는 두 사람 모두 운동하지 않는다. 대신 빠른 거듭제곱(Fast Exponentiation)에 관해 이야기를 나눈다. (상당히 특이한 잡담이다.)

대화를 마친 뒤에는 각자 다음 운동 장소로 이동한다.

Iahub 또는 Iahubina가 운동한 칸에서 소모한 칼로리는 모두 총합에 포함된다.

당신의 임무는 두 사람이 운동하여 소모하는 칼로리의 총합이 최대가 되도록 이동 경로를 계획하는 것이다.

두 사람은 서로 다른 속도로 운동할 수 있으므로, 만나는 칸에 도달하기까지 지나온 칸의 개수는 서로 달라도 된다는 점에 유의하라.

## 입력

첫 번째 줄에는 두 정수 `n`, `m`이 주어진다.

- `3 ≤ n, m ≤ 1000`
- `n`: 체육관 격자의 행 수
- `m`: 체육관 격자의 열 수

이어서 `n`개의 줄에 걸쳐 각 줄마다 `m`개의 정수가 주어진다.

- `0 ≤ a[i][j] ≤ 10⁵`
- `a[i][j]`: `i`번째 행, `j`번째 열에서 운동했을 때 소모하는 칼로리

## 출력

두 사람이 주어진 조건을 만족하며 운동했을 때 얻을 수 있는 최대 칼로리 소모량의 총합을 정수 하나로 출력한다.

## 예제 입력 1

```
3 3
100 100 100
100 1 100
100 100 100
```

## 예제 출력 1

```
800
```

## 예제 설명 1

Iahub는 다음 순서로 이동한다.

`a[1][1] → a[1][2] → a[2][2] → a[3][2] → a[3][3]`

Iahubina는 다음 순서로 이동한다.

`a[3][1] → a[2][1] → a[2][2] → a[2][3] → a[1][3]`

두 사람은 `a[2][2]`에서 만나며, 이 칸에서는 운동하지 않는다.

따라서 총 칼로리 소모량은 `800`이다.
