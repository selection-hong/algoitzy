## [Magic Ship 문제 링크](https://codeforces.com/problemset/problem/1117/C?utm_source=chatgpt.com)

# C. Magic Ship

- 난이도: 1900
- 시간 제한: 2초
- 메모리 제한: 256MB

## 문제 설명

당신은 배의 선장이다.

처음에 당신은 좌표 `(x1, y1)`에 위치해 있으며, 좌표 `(x2, y2)`까지 이동하려고 한다.

바다의 모든 위치는 데카르트 좌표계로 표현할 수 있다.

당신은 일기예보를 알고 있다. 일기예보는 `U`, `D`, `L`, `R` 문자로만 이루어진 길이 `n`의 문자열 `s`이다.

각 문자는 바람이 부는 방향을 나타낸다.

또한 일기예보는 주기적으로 반복된다.

- 첫 번째 날에는 `s[1]` 방향으로 바람이 분다.
- 두 번째 날에는 `s[2]` 방향으로 바람이 분다.
- `n`번째 날에는 `s[n]` 방향으로 바람이 분다.
- `(n+1)`번째 날에는 다시 `s[1]` 방향으로 바람이 분다.

이후에도 같은 방식으로 반복된다.

바람에 따른 배의 좌표 변화는 다음과 같다.

- `U`: 배가 `(x, y)`에서 `(x, y+1)`로 이동한다.
- `D`: 배가 `(x, y)`에서 `(x, y-1)`로 이동한다.
- `L`: 배가 `(x, y)`에서 `(x-1, y)`로 이동한다.
- `R`: 배가 `(x, y)`에서 `(x+1, y)`로 이동한다.

배는 매일 상하좌우 네 방향 중 하나로 이동하거나 제자리에 머무를 수 있다.

배가 직접 이동한다면 정확히 1단위 거리만큼 이동한다.

배의 자체 이동과 바람에 의한 이동은 합산된다.

배가 제자리에 머무르면 바람에 의한 이동만 적용된다.

예를 들어 바람이 `U` 방향으로 불 때 다음과 같다.

- 배가 `L` 방향으로 이동하면 `(x, y)`에서 `(x-1, y+1)`로 이동한다.
- 배가 `U` 방향으로 이동하면 `(x, y)`에서 `(x, y+2)`로 이동한다.

당신의 임무는 배가 목표 좌표 `(x2, y2)`에 도달하는 데 필요한 최소 일수를 구하는 것이다.

## 입력

첫 번째 줄에는 두 정수 `x1, y1`이 주어진다.

- `0 ≤ x1, y1 ≤ 10⁹`
- `(x1, y1)`: 배의 초기 좌표를 의미한다.

두 번째 줄에는 두 정수 `x2, y2`가 주어진다.

- `0 ≤ x2, y2 ≤ 10⁹`
- `(x2, y2)`: 배의 목표 좌표를 의미한다.

초기 좌표와 목표 좌표는 서로 다름이 보장된다.

세 번째 줄에는 정수 `n`이 주어진다.

- `1 ≤ n ≤ 10⁵`
- `n`: 바람의 방향을 나타내는 문자열의 길이이다.

네 번째 줄에는 문자열 `s`가 주어진다.

- 문자열 `s`는 `U`, `D`, `L`, `R` 문자로만 구성된다.
- `s[i]`: 해당 날짜에 바람이 부는 방향을 의미한다.

## 출력

배가 목표 좌표 `(x2, y2)`에 도달하는 데 필요한 최소 일수를 한 줄에 출력한다.

목표 좌표에 도달할 수 없다면 `-1`을 출력한다.

## 예제 입력 1

```
0 0
4 6
3
UUU
```

## 예제 출력 1

```
5
```

## 예제 입력 2

```
0 3
0 0
3
UDD
```

## 예제 출력 2

```
3
```

## 예제 입력 3

```
0 0
0 1
1
L
```

## 예제 출력 3

```
-1
```

## 참고

첫 번째 예제에서 배는 `"RRRRU"` 순서로 이동해야 한다.

이때 배의 좌표는 다음과 같이 변한다.

`(0,0) → (1,1) → (2,2) → (3,3) → (4,4) → (4,6)`

두 번째 예제에서 배는 `"DD"` 순서로 이동해야 한다.

세 번째 날에는 제자리에 머무른다.

이때 배의 좌표는 다음과 같이 변한다.

`(0,3) → (0,3) → (0,1) → (0,0)`

세 번째 예제에서 배는 절대로 좌표 `(0,1)`에 도달할 수 없다.
