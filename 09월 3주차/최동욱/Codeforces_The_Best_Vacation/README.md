## [The Best Vacation 링크](https://codeforces.com/problemset/problem/1358/D)

### 문제 번역

당신은 오랫동안 Coronavirus-chan을 좋아해 왔지만, 지금까지 그녀가 어디에 사는지는 알지 못했다. 그리고 방금 그녀가 **Naha**라는 아주 먼 곳에 살고 있다는 사실을 알게 되었다.

당신은 즉시 휴가를 내고 Coronavirus-chan을 만나러 가기로 했다.

휴가는 정확히 `x`일 동안이며, 그 `x`일 동안 친구를 방문하게 된다. 즉, 당신은 **연속된 정확히 `x`일** 동안 Coronavirus-chan을 방문한다.

Naha에서는 매우 특이한 달력을 사용한다.

1년에는 `n`개의 달이 있고, `i`번째 달은 정확히 `di`일로 이루어져 있다.

`i`번째 달의 날짜는 `1`일부터 `di`일까지 번호가 매겨져 있다.

Naha에는 윤년이 없다.

Coronavirus-chan의 기분, 즉 당신을 안아주고 싶은 정도는 **그 달의 며칠째인지**에 따라 달라진다.

구체적으로 어떤 달의 `j`번째 날에 Coronavirus-chan을 방문하면, 당신은 **`j`번의 포옹**을 받을 수 있다.

당신은 이 특징을 알고 있으므로, 휴가 동안 받을 수 있는 포옹의 총합을 최대화하고 싶다.

여행의 시작과 끝이 **반드시 같은 해에 속할 필요는 없다.**

## 입력

첫 번째 줄에 두 정수 `n`, `x`가 주어진다.

* `n` : 1년을 구성하는 달의 개수
* `x` : 친구를 방문할 수 있는 연속된 날짜 수

`1 ≤ n ≤ 2 × 10^5`

두 번째 줄에는 `n`개의 정수

`d1, d2, ..., dn`

이 주어진다.

`di`는 `i`번째 달의 날짜 수를 의미한다.

`1 ≤ di ≤ 10^6`

또한 다음 조건이 보장된다.

`1 ≤ x ≤ d1 + d2 + ... + dn`

즉, 휴가 기간 `x`는 한 해의 전체 날짜 수를 초과하지 않는다.

## 출력

연속된 `x`일 동안 여행했을 때 받을 수 있는 **포옹 횟수의 최댓값**을 출력한다.
