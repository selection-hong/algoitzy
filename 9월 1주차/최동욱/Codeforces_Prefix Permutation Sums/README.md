## 문제 링크 : [Codeforces Prefix Permutation Sums](https://codeforces.com/problemset/problem/1851/D)

## 문제 번역

친구들은 n개의 원소로 이루어진 배열을 가지고 있었고, 그 배열의 누적합 배열을 계산한 뒤 당신에게 전달했습니다. 하지만 전달 과정에서 실수로 원소 하나를 잃어버렸습니다. 주어진 배열이 어떤 순열의 누적합 배열에서 원소 하나가 빠진 형태가 될 수 있는지 판별하는 것이 당신의 과제입니다.

n개의 원소로 이루어진 순열이란 1부터 n까지의 수가 각각 정확히 한 번씩 등장하는 배열입니다.

배열 a의 누적합 배열 b는 다음과 같이 정의됩니다.

b_i = ∑(j=1부터 i까지) a_j, 1 ≤ i ≤ n

예를 들어 원래 순열이 [1, 5, 2, 4, 3]이었다면 누적합 배열은 [1, 6, 8, 12, 15]입니다. 이 중 원소 하나를 잃어버리면 예를 들어 [6, 8, 12, 15] 또는 [1, 6, 8, 15]와 같은 배열을 얻을 수 있습니다.

또한 [1, 2, 100]과 같은 배열은 어떤 순열에도 대응하지 않는다는 것을 알 수 있습니다.

입력

첫 번째 줄에는 테스트 케이스의 개수 t (1 ≤ t ≤ 10^4)가 주어집니다.

각 테스트 케이스의 첫 번째 줄에는 원래 배열의 크기 n (2 ≤ n ≤ 2×10^5)이 주어집니다.

두 번째 줄에는 누적합 배열에서 원소 하나가 빠진 n−1개의 양의 정수 a_i (1 ≤ a_i ≤ 10^18)가 주어집니다. 또한 a_{i-1} < a_i를 만족합니다.

모든 테스트 케이스에 대한 n의 합은 2×10^5를 넘지 않습니다.

출력

각 테스트 케이스마다 이러한 순열이 존재하면 "YES", 존재하지 않으면 "NO"를 출력합니다.

"YES"와 "NO"는 대소문자를 구분하지 않습니다. 예를 들어 "yEs", "yes", "Yes"도 모두 긍정적인 답으로 인정됩니다.
