[문제 설명]

N개의 도시가 주어진다. 각 도시는 0부터 N-1까지 ID값을 가진다. 그리고 각 도시마다 1개의 전기차 충전소가 존재한다.
각 충전소는 단위 거리당 충전 비용을 가지고, 전기차의 충전 용량은 무한대이다.

도시를 연결하는 단방향 도로가 추가될 때, 해당 도로의 ID와 거리가 주어진다.

출발 도시에서 도착 도시로 이동할 때 필요한 최소 충전 비용을 구하고자 한다.
전기차의 충전 용량은무한대이기 때문에 충전 비용이 낮은 충전소에서 충전을 미리 하는 것이 유리하다.

[Fig. 1]은 5개의 도시가 주어진 예이다.

[Fig. 1]

(0 --> 1 --> 3 --> 4) 경로로 가는 경우, 0번 도시에서 9 x 60 = 540 비용으로 충전하고, 1번 도시로 이동하여 7 x 70 = 490 비용으로 충전하고,
3번 도시로 이동하여 3 x 20 = 60 비용으로 충전하면, 총 1090 비용으로 4번 도시에 도착할 수 있다.

(0 --> 2 --> 1 --> 3 --> 4) 경로로 가는 경우, 0번 도시에서 9 x 30 = 270 비용으로 충전하고, 2번 도시로 이동한다.
2번 도시의 충전 비용이 1, 3, 4번 도시보다 낮기 때문에 여기서 4번까지 가기 위해 필요한 모든 전기를 충전한다.
그 비용은 2 x (40 + 70 + 20) = 260 이다. 따라서 총 530 비용으로 4번 도시에 도착할 수 있고,
이 비용이 0번 도시에서 4번 도시로 가기 위해 필요한 최소 충전 비용이다.

 

아래 API 설명을 참조하여 각 함수를 구현하라.

※ 아래 함수 signature는 C/C++에 대한 것으로 다른 언어에 대해서는 제공되는 Main과 User Code를 참고하라.

 

아래는 User Code 부분에 작성해야 하는 API 의 설명이다.

 

 

void init(int N, int mCost[], int K, int mId[], int sCity[], int eCity[], int mDistance[])

각 테스트 케이스의 처음에 호출된다.

 

N개의 도시가 주어진다. 각 도시는 0부터 N-1까지 ID값을 가진다.

N개의 단위 거리당 충전 비용이 mCost 배열로 주어진다.

K개의 도로 정보가 주어진다. 각 도로의 ID, 출발 도시와 도착 도시, 그리고 거리가 주어진다.

 

단방향 도로이기 때문에 출발 도시에서 도착 도시로만 갈 수 있다.

출발 도시와 도착 도시의 순서쌍이 동일한 도로는 없다.

출발 도시와 도착 도시가 서로 같은 경우는 없다.

도로 ID가 서로 같은 경우는 없다.

 

Parameters

N: 도시의 개수 ( 5 ≤ N ≤ 300 )

 

(0 ≤ i ＜ N)인 모든 i에 대해,

mCost[i]: 도시 i의 단위 거리당 충전 비용 ( 1 ≤ mCost[i] ≤ 2,000 )

 

K: 도로의 개수 ( 4 ≤ K ≤ 2,000 )

 

(0 ≤ i ＜ K)인 모든 i에 대해,

mId[i]: 도로 i의 ID ( 1 ≤ mId[i] ≤ 1,000,000,000 )

sCity[i]: 도로 i의 출발 도시 ( 0 ≤ sCity[i] < N )

eCity[i]: 도로 i의 도착 도시 ( 0 ≤ eCity[i] < N )

mDistance[i]: 도로 i의 거리 ( 1 ≤ mDistance[i] ≤ 2,000 )

 

void add(int mId, int sCity, int eCity, int mDistance)

출발 도시가 sCity이고, 도착 도시가 eCity이고, 거리가 mDistance인 mId 도로를 추가한다.

 

단방향 도로이기 때문에 출발 도시에서 도착 도시로만 갈 수 있다.

init()에 없던 새로운 도시는 주어지지 않는다.

sCity에서 eCity로 가는 도로가 이미 존재하는 경우는 없다.

sCity와 eCity가 서로 같은 경우는 없다.

mId 값으로 이미 존재하는 도로의 ID가 주어지는 경우는 없다.

 

Parameters

mId: 도로의 ID ( 1 ≤ mId ≤ 1,000,000,000 )

sCity: 도로의 출발 도시 ( 0 ≤ sCity < N )

eCity: 도로의 도착 도시 ( 0 ≤ eCity < N )

mDistance: 도로의 거리 ( 1 ≤ mDistance ≤ 2,000 )

 

void remove(int mId)

mId 도로를 제거한다.

 

존재하지 않는 도로의 ID가 주어지는 경우는 없다.

 

Parameters

mId: 도로의 ID ( 1 ≤ mId ≤ 1,000,000,000 )

 

int cost(int sCity, int eCity)

sCity에서 eCity로 가는데 필요한 최소 충전 비용을 반환한다.

 

sCity와 eCity가 서로 같은 경우는 없다.

 

Parameters

sCity: 출발 도시 ( 0 ≤ sCity < N )

eCity: 도착 도시 ( 0 ≤ eCity < N )

 

Returns

sCity에서 eCity로 이동이 가능하다면, 필요한 최소 충전 비용을 반환한다.

불가능하다면, -1을 반환한다.
