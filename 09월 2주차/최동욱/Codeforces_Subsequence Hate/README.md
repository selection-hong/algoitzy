# [Subsequence Hate 문제 링크](https://codeforces.com/problemset/problem/1363/B)

## SubSequence Hate 문제 번역

Shubham은 이진 문자열 s를 가지고 있다. 이진 문자열이란 문자 "0"과 "1"로만 이루어진 문자열이다.

그는 문자열에 대해 다음 연산을 원하는 만큼 수행할 수 있다.

* 문자열에서 하나의 인덱스를 선택하고, 해당 위치의 문자를 뒤집는다. 즉, 문자가 "0"이었다면 "1"로 바꾸고, "1"이었다면 "0"으로 바꾼다.

문자열이 부분 수열(subsequence)로 "010" 또는 "101"을 포함하지 않는다면 좋은 문자열(good string)이라고 한다.

예를 들어 "1001"은 "101"을 부분 수열로 포함하므로 좋은 문자열이 아니다. 반면 "1000"은 "010"과 "101"을 모두 부분 수열로 포함하지 않으므로 좋은 문자열이다.

문자열을 좋은 문자열로 만들기 위해 필요한 최소 연산 횟수를 구하여라. 이러한 연산을 통해 어떤 문자열이든 좋은 문자열로 만들 수 있음이 보장된다.

문자열 a가 문자열 b의 부분 수열이라는 것은, b에서 몇 개의 문자(0개 또는 모든 문자를 포함하여)를 삭제하여 a를 만들 수 있다는 의미이다.

---

### 입력

첫 번째 줄에는 테스트 케이스의 수 t(1≤t≤100)가 주어진다. <br>
이후 t개의 줄에 각각 하나의 이진 문자열 s(1≤|s|≤1000)가 주어진다.

--- 

### 출력

각 문자열에 대해 좋은 문자열로 만들기 위해 필요한 최소 연산 횟수를 출력한다.
