# Codeforces 4C - Registration System

## 문제 설명

Berland에서 새로운 이메일 서비스 **Berlandesk**가 곧 출시될 예정입니다.

사이트 관리자는 서비스를 빠르게 출시하기 위해 회원가입 시스템의 프로토타입을 구현하려고 합니다.

회원가입 시스템은 다음과 같이 동작합니다.

사용자가 회원가입을 할 때 원하는 사용자 이름을 시스템에 전달합니다.

- 해당 이름이 데이터베이스에 존재하지 않는다면
  - 이름을 데이터베이스에 등록합니다.
  - `OK`를 출력합니다.

- 해당 이름이 이미 데이터베이스에 존재한다면
  - 기존 이름 뒤에 숫자를 붙여 새로운 사용자 이름을 생성합니다.
  - 생성된 이름을 사용자에게 알려줍니다.
  - 해당 이름도 데이터베이스에 등록합니다.

새로운 이름은 다음 규칙으로 생성됩니다.

원래 이름이 `name`이라면

```text
name1
name2
name3
...
```

순서로 확인하여, 아직 데이터베이스에 존재하지 않는 이름 중 **가장 작은 양의 정수를 붙인 이름**을 선택합니다.

예를 들어 `name`과 `name1`이 이미 존재하고 `name2`가 존재하지 않는다면 새로운 이름은

```text
name2
```

가 됩니다.

---

## 입력

첫 번째 줄에 회원가입 요청의 개수 `n`이 주어집니다.

```text
1 ≤ n ≤ 100000
```

이후 `n`개의 줄에 각각 사용자가 요청한 이름이 주어집니다.

각 이름은 다음 조건을 만족합니다.

- 빈 문자열이 아닙니다.
- 길이는 최대 32자입니다.
- 모든 문자는 영문 소문자입니다.

---

## 출력

각 회원가입 요청마다 한 줄씩 결과를 출력합니다.

- 요청한 이름을 바로 등록할 수 있다면

```text
OK
```

를 출력합니다.

- 이미 해당 이름이 존재한다면 시스템이 생성한 새로운 이름을 출력합니다.

---

## 예제 1

### 입력

```text
4
abacaba
acaba
abacaba
acab
```

### 출력

```text
OK
OK
abacaba1
OK
```

---

## 예제 2

### 입력

```text
6
first
first
second
second
third
third
```

### 출력

```text
OK
first1
OK
second1
OK
third1
```
