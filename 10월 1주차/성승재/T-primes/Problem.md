# Codeforces 230B - T-primes

## 문제 설명

소수(Prime Number)는 **서로 다른 양의 약수를 정확히 2개 가지는 양의 정수**입니다.

이와 비슷하게, 서로 다른 양의 약수를 **정확히 3개 가지는 양의 정수 `t`**를 **T-prime**이라고 정의합니다.

`n`개의 양의 정수가 주어집니다.

각 숫자가 T-prime인지 아닌지를 판별하세요.

---

## 입력

첫 번째 줄에 배열에 포함된 숫자의 개수 `n`이 주어집니다.

```text
1 ≤ n ≤ 100000
```

두 번째 줄에는 `n`개의 정수 `x_i`가 공백으로 구분되어 주어집니다.

```text
1 ≤ x_i ≤ 10^12
```

---

## 출력

각 숫자마다 한 줄씩 결과를 출력합니다.

- `x_i`가 T-prime이라면

```text
YES
```

- T-prime이 아니라면

```text
NO
```

를 출력합니다.

---

## 예제

### 입력

```text
3
4 5 6
```

### 출력

```text
YES
NO
NO
```

---

## 예제 설명

주어진 숫자는 `4`, `5`, `6`입니다.

### 4

`4`의 양의 약수는 다음과 같습니다.

```text
1, 2, 4
```

서로 다른 약수가 정확히 3개이므로 `4`는 T-prime입니다.

따라서

```text
YES
```

를 출력합니다.

### 5

`5`의 약수는 다음과 같습니다.

```text
1, 5
```

약수가 2개이므로 T-prime이 아닙니다.

따라서

```text
NO
```

를 출력합니다.

### 6

`6`의 약수는 다음과 같습니다.

```text
1, 2, 3, 6
```

약수가 4개이므로 T-prime이 아닙니다.

따라서

```text
NO
```

를 출력합니다.
