# [Codeforces Epic Transformation 문제 링크](https://codeforces.com/problemset/problem/1506/D)

## Epic Transformation

길이가 `n`인 정수 배열 `a`가 주어집니다.

배열 `a`에 다음 연산을 **0번 이상** 수행할 수 있습니다.

- 배열에서 **서로 다른 값을 가진 두 원소** `a_i`, `a_j`를 선택합니다.
- 배열에서 `i`번째 원소와 `j`번째 원소를 제거합니다.

예를 들어 `n = 6`이고

```text
a = [1, 6, 1, 1, 4, 4]
```

라면 다음과 같이 연산할 수 있습니다.

- `i = 1`, `j = 5`를 선택하면 배열은 `[6, 1, 1, 4]`가 됩니다.
- 이후 `i = 1`, `j = 2`를 선택하면 배열은 `[1, 4]`가 됩니다.

어떤 순서로 연산을 수행했을 때, **최종적으로 남을 수 있는 배열의 최소 길이**를 구하세요.

### 입력

첫 번째 줄에 테스트 케이스의 개수 `t`가 주어집니다.

```text
1 ≤ t ≤ 10^4
```

각 테스트 케이스의 첫 번째 줄에는 배열의 길이 `n`이 주어집니다.

```text
1 ≤ n ≤ 2 × 10^5
```

두 번째 줄에는 `n`개의 정수

```text
a1, a2, ..., an
```

이 주어집니다.

```text
1 ≤ ai ≤ 10^9
```

모든 테스트 케이스에서 `n`의 합은 `2 × 10^5`를 넘지 않습니다. 

### 출력

각 테스트 케이스마다 연산을 적절히 수행했을 때 **남길 수 있는 배열의 최소 길이**를 출력합니다.

### 예제

```text
입력
5
6
1 6 1 1 4 4
2
1 2
2
1 1
5
4 5 4 5 4

```

```text
출력
```
