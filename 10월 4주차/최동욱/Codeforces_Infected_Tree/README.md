# C. Infected Tree

- 난이도: 1600
- 시간 제한: 3초
- 메모리 제한: 256MB

## 문제 설명

바이틀랜드(Byteland)는 아름다운 나무들로 유명한 나라이다.

미샤(Misha)는 `n`개의 정점으로 이루어진 이진 트리(Binary Tree)를 발견했다.

트리의 정점에는 `1`부터 `n`까지 번호가 매겨져 있다.

이 문제에서 이진 트리는 다음 조건을 만족한다.

- 사이클이 없는 연결된 무방향 그래프이다.
- 정점은 `n`개, 간선은 `n - 1`개이다.
- 각 정점의 차수는 최대 3이다.
- 루트(Root)는 1번 정점이며, 루트의 차수는 최대 2이다.

불행히도 루트 정점이 감염되었다.

이후 다음 과정이 총 `n`번 진행된다.

한 번의 과정에서는 다음 두 단계가 순서대로 수행된다.

1. 미샤는 다음 두 행동 중 하나를 선택한다.
   - 감염되지 않았고 삭제되지 않은 정점 하나를 선택하여 삭제한다.
   - 아무 행동도 하지 않는다.
2. 감염된 정점과 간선으로 연결된 모든 정점으로 감염이 확산된다.

정점을 삭제하면 해당 정점에 연결된 모든 간선도 함께 삭제된다.

이미 감염된 정점은 계속 감염된 상태로 남는다.

미샤는 생각할 시간이 부족하다.

총 `n`번의 과정이 끝난 후 감염되지 않은 정점의 개수를 최대화하라.

단, 삭제된 정점은 구한 정점의 개수에 포함되지 않는다.

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어진다.

\- `1 ≤ t ≤ 5000`

각 테스트 케이스는 다음과 같이 구성된다.

- 첫 번째 줄에는 정수 `n`이 주어진다.
  - `2 ≤ n ≤ 3 × 10⁵`: 트리의 정점 개수
- 다음 `n - 1`개의 줄에는 두 정수 `u`, `v`가 주어진다.
  - `1 ≤ u, v ≤ n`
  - 정점 `u`와 정점 `v`가 간선으로 연결되어 있음을 의미한다.

주어진 그래프는 1번 정점을 루트로 하는 이진 트리임이 보장된다.

모든 테스트 케이스에 대한 `n`의 합은 `3 × 10⁵`를 초과하지 않는다.

## 출력

각 테스트 케이스마다 한 줄에 다음 값을 출력한다.

\- 감염으로부터 구할 수 있는 정점의 최대 개수

## 예제 설명

### 첫 번째 테스트 케이스

정점이 2개인 트리가 주어진다.

초기에는 1번 정점이 감염되어 있다.

2번 정점을 삭제하면 감염 확산을 막을 수 있지만, 삭제된 정점은 구한 정점으로 계산하지 않는다.

따라서 구할 수 있는 정점은 총 0개이다.

### 두 번째 테스트 케이스

정점이 4개인 트리가 주어진다.

초기에는 1번 정점이 감염되어 있다.

첫 번째 과정에서 2번 정점을 삭제하면 2번 정점과 연결된 모든 간선도 제거된다.

따라서 3번과 4번 정점은 감염되지 않은 상태로 남는다.

구할 수 있는 정점은 총 2개이므로 정답은 `2`이다.
