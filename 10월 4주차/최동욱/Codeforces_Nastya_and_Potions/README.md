# E. Nastya and Potions

- 난이도: 1500
- 시간 제한: 3초
- 메모리 제한: 256MB

## 문제 설명

연금술사 나스티야(Nastya)는 여러 물약을 혼합하는 것을 좋아한다.

총 `n`종류의 물약이 있으며, `i`번 물약 하나를 구매하려면 `c[i]`개의 동전이 필요하다.

각 물약은 다른 물약 여러 개를 혼합하여 만들 수 있다.

물약을 혼합하는 과정에는 다음 조건이 적용된다.

- 각 물약을 만드는 혼합 방법은 최대 한 가지이다.
- 혼합에 사용된 물약은 소모된다.
- 어떤 물약도 하나 이상의 혼합 과정을 거쳐 자기 자신을 만드는 데 사용될 수 없다.

숙련된 연금술사인 나스티야는 이미 `k`종류의 물약 `p1, p2, ..., pk`를 무제한으로 보유하고 있다.

하지만 나스티야는 다음에 어떤 물약을 만들지 아직 결정하지 못했다.

이를 결정하기 위해 나스티야는 각 물약을 하나 얻는 데 필요한 최소 동전 개수를 알고 싶어 한다.

`1 ≤ i ≤ n`인 모든 물약에 대해, 해당 물약을 하나 얻는 데 필요한 최소 동전 개수를 구하라.

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어진다.

\- `1 ≤ t ≤ 10⁴`

각 테스트 케이스는 다음과 같이 구성된다.

- 첫 번째 줄에는 두 정수 `n`, `k`가 주어진다.
  - `1 ≤ k < n ≤ 2 × 10⁵`
  - `n`: 전체 물약의 종류 개수
  - `k`: 나스티야가 무제한으로 보유한 물약의 종류 개수
- 두 번째 줄에는 `n`개의 정수 `c1, c2, ..., cn`이 주어진다.
  - `1 ≤ c[i] ≤ 10⁹`
  - `c[i]`: `i`번 물약 하나를 구매하는 데 필요한 동전 개수
- 세 번째 줄에는 서로 다른 `k`개의 정수 `p1, p2, ..., pk`가 주어진다.
  - `1 ≤ p[i] ≤ n`
  - 나스티야가 무제한으로 보유한 물약의 번호를 의미한다.
- 다음 `n`개의 줄에는 각 물약을 혼합하여 만드는 방법이 주어진다.
  - 각 줄은 `i`번 물약의 혼합 방법을 나타낸다.
  - 첫 번째 정수 `m[i]`는 `i`번 물약을 만드는 데 필요한 물약의 개수이다.
    - `0 ≤ m[i] < n`
  - 이어서 `m[i]`개의 서로 다른 정수 `e1, e2, ..., em[i]`가 주어진다.
    - `1 ≤ e[j] ≤ n`
    - `e[j] ≠ i`
    - `i`번 물약을 만들기 위해 필요한 물약의 번호를 의미한다.
  - `m[i] = 0`이면 해당 물약은 혼합으로 만들 수 없으며, 구매를 통해서만 얻을 수 있다.

어떤 물약도 하나 이상의 혼합 과정을 통해 자기 자신을 만드는 데 사용될 수 없음이 보장된다.

모든 테스트 케이스에 대한 `n`의 합은 `2 × 10⁵`를 초과하지 않는다.

모든 테스트 케이스에 대한 `m[i]`의 합 역시 `2 × 10⁵`를 초과하지 않는다.

## 출력

\- `i`번째 정수는 `i`번 물약 하나를 얻는 데 필요한 최소 동전 개수이다.

## 예제 설명

### 예제 입력 1의 첫 번째 테스트 케이스

총 5종류의 물약이 주어진다.

각 물약의 구매 비용은 다음과 같다.

| 물약 번호 | 구매 비용 |
| ----- | ----- |
| 1     | 30    |
| 2     | 8     |
| 3     | 3     |
| 4     | 5     |
| 5     | 10    |

나스티야는 3번 물약을 무제한으로 보유하고 있다.

각 물약을 얻는 최적의 방법은 다음과 같다.

- 1번 물약: 2번, 4번, 5번 물약을 구매한 뒤 혼합하면 된다. 필요한 동전은 `8 + 5 + 10 = 23`개이다.
- 2번 물약: 혼합으로 만들 수 없으므로 동전 `8`개를 사용하여 구매한다.
- 3번 물약: 이미 무제한으로 보유하고 있으므로 동전이 필요하지 않다.
- 4번 물약: 다른 물약을 혼합하여 만드는 것보다 동전 `5`개를 사용하여 구매하는 것이 더 저렴하다.
- 5번 물약: 혼합으로 만들 수 없으므로 동전 `10`개를 사용하여 구매한다.

따라서 정답은 다음과 같다.

```
23 8 0 5 10
```
