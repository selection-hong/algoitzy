## [Sending a Sequence Over the Network 문제 링크](https://codeforces.com/problemset/problem/1741/E)

# E. Sending a Sequence Over the Network

- **난이도:** 1600
- **시간 제한:** 1초
- **메모리 제한:** 256MB

## 문제 설명

수열 `a`는 다음과 같은 방식으로 네트워크를 통해 전송된다.

1. 수열 `a`를 여러 구간으로 나눈다.
   - 수열의 모든 원소는 정확히 하나의 구간에 속해야 한다.
   - 각 구간은 수열에서 연속된 원소들로 구성되어야 한다.
2. 각 구간의 길이를 해당 구간의 왼쪽 또는 오른쪽에 기록한다.
3. 이렇게 만들어진 수열 `b`를 네트워크를 통해 전송한다.

예를 들어, 수열 `a = [1, 2, 3, 1, 2, 3]`을 전송한다고 하자.

수열을 다음과 같이 구간으로 나누었다고 가정한다.

`[1] + [2, 3, 1] + [2, 3]`

각 구간의 길이를 왼쪽 또는 오른쪽에 기록하는 방식에 따라 다음과 같은 수열 `b`를 만들 수 있다.

- `b = [1, 1, 3, 2, 3, 1, 2, 3, 2]`
- `b = [1, 1, 3, 2, 3, 1, 2, 2, 3]`
- `b = [1, 1, 2, 3, 1, 3, 2, 2, 3]`
- `b = [1, 1, 2, 3, 1, 3, 2, 3, 2]`

수열을 다른 방식으로 구간 분할했다면 전송되는 수열도 달라질 수 있다.

수열 `b`가 주어진다.

**이 수열 `b`가 위의 방식으로 네트워크를 통해 전송될 수 있는지 판별하라.**

즉, 어떤 수열 `a`가 존재하여 위의 전송 과정을 거쳤을 때 주어진 수열 `b`가 만들어질 수 있는지 확인해야 한다.

---

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어진다.

- `1 ≤ t ≤ 10⁴`

각 테스트 케이스는 두 줄로 구성된다.

- 첫 번째 줄에는 수열 `b`의 길이 `n`이 주어진다.
  - `1 ≤ n ≤ 2 × 10⁵`
- 두 번째 줄에는 수열 `b`의 원소 `b₁, b₂, ..., bₙ`이 주어진다.
  - `1 ≤ bᵢ ≤ 10⁹`

모든 테스트 케이스에 대한 `n`의 합은 `2 × 10⁵`를 초과하지 않는다.

---

## 출력

각 테스트 케이스마다 한 줄에 다음 중 하나를 출력한다.

- `YES`: 주어진 수열 `b`가 어떤 수열 `a`를 전송하는 과정에서 만들어질 수 있는 경우
- `NO`: 그러한 수열 `a`가 존재하지 않는 경우

대소문자는 구분하지 않는다.

## 예제 설명

### 첫 번째 테스트 케이스

수열 `a = [1, 2, 3, 1, 2, 3]`을 다음과 같이 분할할 수 있다.

`[1] + [2, 3, 1] + [2, 3]`

이를 전송 형식으로 변환하면 다음 수열을 얻을 수 있다.

`b = [1, 1, 2, 3, 1, 3, 2, 2, 3]`

따라서 `YES`이다.

### 두 번째 테스트 케이스

수열 `a = [12, 7, 5]`를 다음과 같이 분할할 수 있다.

`[12] + [7, 5]`

이를 전송 형식으로 변환하면 다음 수열을 얻는다.

`b = [12, 1, 2, 7, 5]`

따라서 `YES`이다.

### 세 번째 테스트 케이스

수열 `a = [7, 8, 9, 10, 3]`을 하나의 구간으로 구성할 수 있다.

`[7, 8, 9, 10, 3]`

구간의 길이인 `5`를 왼쪽에 기록하면 다음 수열이 된다.

`b = [5, 7, 8, 9, 10, 3]`

따라서 `YES`이다.

### 네 번째 테스트 케이스

주어진 수열 `b`를 만들 수 있는 수열 `a`는 존재하지 않는다.

따라서 `NO`이다.
