## [Gardener and Tree 문제 링크](https://codeforces.com/problemset/problem/1593/E)

# E. Gardener and Tree

- **난이도:** 1600
- **시간 제한:** 4초
- **메모리 제한:** 256MB

## 문제 설명

트리(Tree)는 사이클이 없는 연결된 무방향 그래프이다.

이 문제에서는 루트가 없는 트리(Unrooted Tree)를 다룬다.

트리의 리프(Leaf)는 연결된 정점의 개수가 1개 이하인 정점을 의미한다.

정원사 비탈리(Vitaly)는 `n`개의 정점으로 이루어진 트리를 길렀다.

비탈리는 트리를 가지치기하기 위해 다음 작업을 여러 번 수행한다.

**한 번의 작업에서는 현재 트리에 존재하는 모든 리프 정점을 동시에 제거한다.**

작업에는 다음과 같은 특수한 경우가 존재한다.

- 정점이 0개인 트리: 작업을 수행해도 아무 변화가 없다.
- 정점이 1개인 트리: 해당 정점을 리프로 취급하여 제거한다.
- 정점이 2개인 트리: 두 정점 모두 리프로 취급하여 제거한다.

비탈리는 이 작업을 순차적으로 `k`번 수행한다.

**모든 작업을 수행한 후 트리에 남아 있는 정점의 개수를 구하라.**

---

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어진다.

- `1 ≤ t ≤ 10⁴`

각 테스트 케이스 앞에는 빈 줄이 하나 존재한다.

각 테스트 케이스는 다음과 같이 구성된다.

- 첫 번째 줄에는 두 정수 `n`, `k`가 주어진다.
  - `1 ≤ n ≤ 4 × 10⁵`: 트리의 정점 개수
  - `1 ≤ k ≤ 2 × 10⁵`: 수행할 작업 횟수
- 다음 `n - 1`개의 줄에는 두 정수 `u`, `v`가 주어진다.
  - `1 ≤ u, v ≤ n`
  - `u ≠ v`
  - 정점 `u`와 정점 `v`가 간선으로 연결되어 있음을 의미한다.

주어진 그래프는 트리이며, 자기 자신으로 연결되는 간선이나 중복 간선은 존재하지 않는다.

모든 테스트 케이스에 대한 `n`의 합은 `4 × 10⁵`를 초과하지 않는다.

---

각 테스트 케이스마다 한 줄에 다음 값을 출력한다.

- `k`번의 작업을 수행한 후 트리에 남아 있는 정점의 개수

## 예제 설명

### 첫 번째 테스트 케이스

문제에서 제시된 트리에 작업을 한 번 수행한다.

현재 트리에 존재하는 모든 리프 정점을 동시에 제거하면 7개의 정점이 남는다.

따라서 정답은 `7`이다.

### 두 번째 테스트 케이스

정점이 2개인 트리가 주어지고, 총 `200000`번의 작업을 수행한다.

첫 번째 작업에서 두 정점이 모두 제거된다.

이후 작업에서는 트리가 비어 있으므로 아무 변화가 발생하지 않는다.

따라서 정답은 `0`이다.

### 세 번째 테스트 케이스

정점이 3개인 트리가 주어진다.

첫 번째 작업을 수행하면 양 끝의 리프가 제거되어 2번 정점 하나만 남는다.

두 번째 작업에서는 남아 있는 2번 정점도 리프로 취급하여 제거한다.

따라서 정답은 `0`이다.
