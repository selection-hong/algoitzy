## 문제 설명
- N×N 크기의 격자에 0~9 숫자가 적혀 있음
- 같은 숫자끼리 인접한 칸은 하나의 덩어리로 묶음
  - 인접 기준: 상하좌우 + 대각선 (8방향)
- 덩어리 전체의 모양이 속이 꽉 찬 정사각형인 덩어리의 개수를 반환
  - 정사각형은 축에 평행해야 함 (회전한 형태 불인정)
  - 한 변의 길이는 칸 수 기준 2 이상

## 제한 조건
1. 숫자 범위: 0 ≤ 숫자 ≤ 9 (0도 일반 숫자로 취급)
2. 격자 크기: N×N 정사각 격자, N 최대 1000
3. 정사각형 한 변의 길이: 2 이상
4. 시간 및 메모리 제한: 없음

## 입출력
- 입력: 2차원 정수 배열
- 출력: 조건을 만족하는 정사각형 덩어리의 개수 (정수)
- 정사각형이 없으면 0 반환



### 예시 1 → 출력 2
```
1 1 0 2 2
1 1 0 2 2
0 0 0 0 0
3 3 3 0 4
3 3 3 0 4
```
- 1 덩어리: 2×2 정사각형 → 포함
- 2 덩어리: 2×2 정사각형 → 포함
- 0 덩어리: 정사각형 아님
- 3 덩어리: 2×3 직사각형 → 제외
- 4 덩어리: 2×1 → 제외

### 예시 2 → 출력 0
```
1 1 0
1 1 0
0 0 1
```
- 1 덩어리: (2,2)가 (1,1)과 대각선으로 붙어 5칸짜리 덩어리가 됨 → 정사각형 아님
