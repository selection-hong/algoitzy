## 문제 링크 : [Little Girl and Maximum Sum](https://codeforces.com/problemset/problem/276/C)

## 문제 번역
소녀는 배열 쿼리 문제를 매우 좋아합니다.

어느 날 소녀는 꽤 잘 알려진 문제를 발견했습니다. n개의 원소로 이루어진 배열이 있고, 배열의 인덱스는 1부터 시작합니다. 또한 q개의 쿼리가 주어지며, 각 쿼리는 두 정수 l_i, r_i (1 ≤ l_i ≤ r_i ≤ n)로 정의됩니다. 각 쿼리에 대해 인덱스가 l_i부터 r_i까지인 배열 원소들의 합을 구해야 합니다.

소녀는 이 문제가 다소 지루하다고 생각했습니다. 그래서 쿼리에 답하기 전에 배열의 원소 순서를 재배치하여 모든 쿼리 결과의 합이 가능한 한 최대가 되도록 하기로 했습니다. 여러분의 과제는 이 최대 합을 구하는 것입니다.

입력

첫 번째 줄에는 공백으로 구분된 두 정수 n (1 ≤ n ≤ 2×10^5)과 q (1 ≤ q ≤ 2×10^5)가 주어집니다. 각각 배열의 원소 개수와 쿼리의 개수를 의미합니다.

두 번째 줄에는 공백으로 구분된 n개의 정수 a_i (1 ≤ a_i ≤ 2×10^5)가 주어집니다. 이는 배열의 원소들입니다.

이후 q개의 줄에는 각각 공백으로 구분된 두 정수 l_i와 r_i (1 ≤ l_i ≤ r_i ≤ n)가 주어집니다. 이는 i번째 쿼리를 의미합니다.

출력

한 줄에 배열의 원소들을 재배치한 뒤 얻을 수 있는 모든 쿼리 결과 합의 최댓값을 출력합니다.

C++에서 64비트 정수를 입력하거나 출력할 때 %lld 형식 지정자는 사용하지 마십시오. cin, cout 스트림 또는 %I64d 형식 지정자를 사용하는 것이 권장됩니다.
