# [Codeforces Mortal Kombat Tower 문제 링크](https://codeforces.com/problemset/problem/1418/C)

## C. Mortal Kombat Tower

당신과 친구는 Mortal Kombat XI라는 게임을 플레이하고 있다. 당신들은 도전의 탑을 통과하려고 한다.

이 탑에는 `1`번부터 `n`번까지 번호가 매겨진 `n`명의 보스가 있다.

`i`번째 보스의 유형은 `a[i]`로 나타낸다. `i`번째 보스가 쉬운 보스라면 `a[i] = 0`이고, 그렇지 않으면 어려운 보스이며 `a[i] = 1`이다.

한 번의 차례에서 당신 또는 친구는 보스를 1명 또는 2명 처치할 수 있다. 당신과 친구 모두 차례를 건너뛸 수 없으므로, 한 차례에 최소 1명의 보스를 처치해야 한다.

친구의 차례가 끝나면 당신의 차례가 시작되고, 이후 다시 친구의 차례, 당신의 차례가 번갈아 진행된다. **첫 번째 차례는 친구의 차례이다.**

친구는 실력을 키워야 한다. 실제로는 어려운 보스를 처치할 수 없기 때문이다. 따라서 친구는 어려운 보스를 처치하기 위해 **스킵 포인트(skip points)**를 사용한다. 스킵 포인트 1개를 사용하면 어려운 보스 1명을 처치할 수 있다.

당신의 임무는 당신과 친구가 주어진 순서대로 `n`명의 보스를 모두 처치할 때, **친구가 사용해야 하는 스킵 포인트의 최솟값**을 구하는 것이다.

예를 들어, `n = 8`, `a = [1, 0, 1, 1, 0, 1, 1, 1]`이라고 하자.

이 경우 가장 좋은 진행 방법은 다음과 같다.

1. 친구가 첫 번째와 두 번째 보스를 처치한다. 첫 번째 보스를 처치하기 위해 스킵 포인트 1개를 사용한다.
2. 당신이 세 번째와 네 번째 보스를 처치한다.
3. 친구가 다섯 번째 보스를 처치한다.
4. 당신이 여섯 번째와 일곱 번째 보스를 처치한다.
5. 친구가 마지막 보스를 처치하면서 스킵 포인트 1개를 사용한다. 따라서 총 2개의 스킵 포인트를 사용하여 탑을 완료한다.

서로 독립적인 `t`개의 테스트 케이스에 답해야 한다.

## 입력 (Input)

첫 번째 줄에는 테스트 케이스의 수를 나타내는 정수 `t` (`1 ≤ t ≤ 2 × 10^4`)가 주어진다.

이후 `t`개의 테스트 케이스가 주어진다.

각 테스트 케이스의 첫 번째 줄에는 보스의 수를 나타내는 정수 `n` (`1 ≤ n ≤ 2 × 10^5`)이 주어진다.

두 번째 줄에는 `n`개의 정수 `a[1], a[2], ..., a[n]` (`0 ≤ a[i] ≤ 1`)이 주어진다. 여기서 `a[i]`는 `i`번째 보스의 유형을 나타낸다.

모든 테스트 케이스에 대한 `n`의 합은 `2 × 10^5`를 넘지 않는 것이 보장된다.

## 출력 (Output)

각 테스트 케이스마다, 당신과 친구가 주어진 순서대로 `n`명의 보스를 모두 처치하기 위해 **친구가 사용해야 하는 스킵 포인트의 최솟값**을 출력한다.

## 예제 (Example)

**입력**

```
6
8
1 0 1 1 0 1 1 1
5
1 1 1 1 0
7
1 1 1 1 0 0 1
6
1 1 1 1 1 1
1
1
1
0
```

**출력**

```
2
2
2
2
1
0
```
