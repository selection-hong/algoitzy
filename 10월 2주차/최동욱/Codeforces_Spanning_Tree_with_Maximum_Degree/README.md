# [Codeforces 1133F1 - Spanning Tree with Maximum Degree](https://codeforces.com/problemset/problem/1133/F1)

## F1. 최대 차수를 갖는 신장 트리

> **난이도:** 1600  
> **시간 제한:** 3초  
> **메모리 제한:** 256MB

### 문제 설명

$n$개의 정점과 $m$개의 간선으로 이루어진 무방향, 무가중치 연결 그래프가 주어진다.

주어진 그래프에는 자기 자신을 연결하는 간선(셀프 루프)이나 중복 간선이 존재하지 않는다.

모든 정점의 차수 중 **최댓값이 가능한 한 큰 신장 트리**를 하나 찾아야 한다.

정점의 차수(degree)란 해당 정점에 연결된 간선의 개수를 의미한다.

### 입력

첫 번째 줄에는 정점의 개수 $n$과 간선의 개수 $m$이 주어진다.

- $2 \le n \le 2 \cdot 10^5$
- $n-1 \le m \le \min(2\cdot10^5, \frac{n(n-1)}{2})$

이후 $m$개의 줄에는 간선 정보가 주어진다.

각 간선은 두 정수 $v_i$, $u_i$로 표현된다.

- $1 \le v_i,u_i \le n$
- $v_i \ne u_i$

이는 정점 $v_i$와 $u_i$가 간선으로 연결되어 있음을 의미한다.

그래프에는 셀프 루프와 중복 간선이 없으며, 모든 정점이 서로 연결되어 있다.

### 출력

조건을 만족하는 신장 트리의 간선 $n-1$개를 각각 한 줄에 출력한다.

- 출력하는 간선은 반드시 입력으로 주어진 간선 중에서 선택해야 한다.
- 간선의 출력 순서는 상관없다.
- 간선 $(v,u)$와 $(u,v)$는 동일하게 취급한다.
- 가능한 정답이 여러 개라면 아무거나 하나 출력해도 된다.

## 참고 (Note)

### 예제 1

신장 트리에서 정점 $3$에 연결된 간선은 $3$개이다.

이는 신장 트리의 최대 차수이며, 이보다 더 큰 최대 차수를 갖는 신장 트리는 구성할 수 없다.

### 예제 2

신장 트리에서 정점 $1$에 연결된 간선은 $3$개이다.

이는 신장 트리의 최대 차수이며, 이보다 더 큰 최대 차수를 갖는 신장 트리는 구성할 수 없다.

### 예제 3

신장 트리에서 정점 $2$에 연결된 간선은 $4$개이다.

이는 신장 트리의 최대 차수이며, 이보다 더 큰 최대 차수를 갖는 신장 트리는 구성할 수 없다.

이 예제는 대칭적인 구조이므로 정점 $2$ 대신 정점 $5$를 선택해도 거의 동일한 신장 트리를 구성할 수 있다.
