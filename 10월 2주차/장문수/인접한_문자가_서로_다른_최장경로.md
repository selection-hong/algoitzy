# 인접한 문자가 서로 다른 최장 경로

[원문: Longest Path With Different Adjacent Characters](https://leetcode.com/problems/longest-path-with-different-adjacent-characters/)

## 문제 설명

노드 `0`을 루트로 하는 트리가 주어집니다. 트리는 **모든 노드가 연결되어 있고, 사이클이 없는 무방향 그래프**입니다.

트리는 총 `n`개의 노드로 이루어져 있으며, 각 노드에는 `0`부터 `n - 1`까지 번호가 매겨져 있습니다.

트리의 구조는 인덱스가 `0`부터 시작하는 길이 `n`의 배열 `parent`로 표현됩니다.

- `parent[i]`는 노드 `i`의 부모 노드를 나타냅니다.
- 노드 `0`은 루트이므로 `parent[0] == -1`입니다.

또한 길이가 `n`인 문자열 `s`가 주어집니다. `s[i]`는 노드 `i`에 할당된 문자입니다.

트리에서 **경로상 서로 인접한 두 노드의 문자가 항상 서로 다른 경로** 중 가장 긴 경로의 길이를 반환하세요.

경로의 길이는 해당 경로에 포함된 **노드의 개수**입니다.

## 예제 1

**입력**

```text
parent = [-1, 0, 0, 1, 1, 2]
s = "abacbe"
```

**출력**

```text
3
```

**설명**

서로 인접한 두 노드의 문자가 항상 다른 최장 경로 중 하나는 `0 → 1 → 3`입니다.

이 경로에 있는 노드의 문자는 각각 `a → b → c`이므로 조건을 만족합니다. 경로에 포함된 노드가 `3`개이므로 `3`을 반환합니다.

조건을 만족하면서 이보다 더 긴 경로는 존재하지 않습니다.

## 예제 2

**입력**

```text
parent = [-1, 0, 0, 0]
s = "aabc"
```

**출력**

```text
3
```

**설명**

서로 인접한 두 노드의 문자가 항상 다른 최장 경로는 `2 → 0 → 3`입니다.

이 경로에 있는 노드의 문자는 각각 `b → a → c`이므로 조건을 만족합니다. 경로에 포함된 노드가 `3`개이므로 `3`을 반환합니다.

## 제약 조건

- `n == parent.length == s.length`
- `1 <= n <= 10^5`
- 모든 `1 <= i < n`에 대해 `0 <= parent[i] <= n - 1`
- `parent[0] == -1`
- `parent`는 유효한 트리를 나타냅니다.
- `s`는 영어 소문자로만 이루어져 있습니다.
