
# C. k-Tree

- **시간 제한:** 1초
- **메모리 제한:** 256MB
- **난이도:** 1600

## 문제 설명

학생 Lesha는 트리에 관한 강의를 듣고 영감을 받아 **k-Tree**라는 새로운 트리를 만들었습니다.

k-Tree는 다음 조건을 만족하는 무한한 루트 트리입니다.

- 모든 정점은 정확히 `k`개의 자식 정점을 가집니다.
- 모든 간선에는 가중치가 존재합니다.
- 각 정점에서 자식 정점으로 연결되는 `k`개의 간선은 각각 `1, 2, 3, ..., k`의 가중치를 가집니다.

![k-Tree 구조](https://espresso.codeforces.com/5f44e910ac6f25b7db3084c9a710bdc243bed406.png)

Lesha의 친구 Dima는 이 트리를 보고 다음과 같은 궁금증을 갖게 되었습니다.

**루트에서 출발하여 간선 가중치의 합이 정확히 `n`이 되는 경로 중, 가중치가 `d` 이상인 간선을 적어도 하나 포함하는 경로는 몇 개일까요?**

Dima가 답을 구할 수 있도록 도와주세요.

가능한 경로의 수가 매우 클 수 있으므로, 정답을 `1000000007`(10⁹ + 7)로 나눈 나머지를 출력해야 합니다.

## 입력

한 줄에 세 정수 `n`, `k`, `d`가 공백으로 구분되어 주어집니다.

- `1 ≤ n, k ≤ 100`
- `1 ≤ d ≤ k`

## 출력

조건을 만족하는 경로의 수를 `1000000007`로 나눈 나머지를 출력합니다.

## 예제

### 예제 1

**입력**
```
3 3 2
```

**출력**
```
3
```

### 예제 2

**입력**
```
3 3 3
```

**출력**
```
1
```

### 예제 3

**입력**
```
4 3 2
```

**출력**
```
6
```

### 예제 4

**입력**
```
4 5 2
```

**출력**
```
7
```
