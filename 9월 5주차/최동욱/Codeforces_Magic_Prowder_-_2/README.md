# [Codeforces Magic Powder - 2 문제 링크](https://codeforces.com/problemset/problem/670/D2)

## D2. Magic Powder - 2

너에게는 `n`가지 재료가 있고, 각 재료를 이용해 쿠키를 만들 수 있습니다.

쿠키 하나를 만들기 위해서는 `i`번째 재료가 정확히 `a_i`그램 필요합니다.

현재 너는 `i`번째 재료를 `b_i`그램 가지고 있습니다.

또한 너에게는 `k`그램의 **마법 가루**가 있습니다.  
마법 가루 1그램은 원하는 재료 1그램으로 바꿀 수 있습니다.

가지고 있는 재료와 마법 가루를 이용해 만들 수 있는 **쿠키의 최대 개수**를 구하세요.

### 입력

첫 번째 줄에 두 정수 `n`, `k`가 주어집니다.

- `1 ≤ n ≤ 100000`
- `1 ≤ k ≤ 10^9`

두 번째 줄에는 `n`개의 정수 `a_1, a_2, ..., a_n`이 주어집니다.

- `1 ≤ a_i ≤ 10^9`

세 번째 줄에는 `n`개의 정수 `b_1, b_2, ..., b_n`이 주어집니다.

- `1 ≤ b_i ≤ 10^9`

### 출력

만들 수 있는 쿠키의 최대 개수를 출력합니다.
