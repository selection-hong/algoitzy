# [Codeforces Block Sequence 문제 링크](https://codeforces.com/problemset/problem/1881/E)

## E. Block Sequence

길이가 `n`인 정수 수열 `a`가 주어집니다.

수열이 **아름답다(beautiful)** 는 것은, 수열 전체를 여러 개의 연속된 블록으로 나눌 수 있고, 각 블록이 다음 조건을 만족하는 경우입니다.

- 블록의 첫 번째 원소가 `k`라면,
- 그 뒤에 정확히 `k`개의 원소가 이어져야 합니다.

즉, 각 블록의 길이는 `k + 1`이며, 블록의 첫 번째 원소가 뒤따르는 원소의 개수를 나타냅니다.

예를 들어 다음 수열은 아름답습니다.

```text
3 1 4 1 5 0
```

첫 번째 원소 `3`은 뒤의 세 원소 `1 4 1`과 하나의 블록을 이루고, 마지막 원소 `0`은 혼자 하나의 블록을 이룹니다.

반면 다음 수열은 아름답지 않습니다.

```text
1 2 3
```

수열에서 일부 원소를 삭제하여 아름다운 수열로 만들려고 합니다.

삭제할 수 있는 원소의 개수는 제한이 없으며, 남아 있는 원소들의 상대적인 순서는 유지됩니다.

수열을 아름답게 만들기 위해 삭제해야 하는 **최소 원소 개수**를 구하세요.

### 입력

첫 번째 줄에 테스트 케이스의 수 `t`가 주어집니다.

각 테스트 케이스마다:

- 첫 번째 줄에 수열의 길이 `n`이 주어집니다.
- 두 번째 줄에 `n`개의 정수 `a_1, a_2, ..., a_n`이 주어집니다.

모든 테스트 케이스에 대한 `n`의 합은 제한 조건을 넘지 않습니다.

### 출력

각 테스트 케이스마다 수열을 아름답게 만들기 위해 삭제해야 하는 최소 원소 개수를 출력합니다.
