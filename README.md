# 🌱 모코숲

### 함께 고민하고, 함께 성장하는 알고리즘 스터디

모코숲은 알고리즘 문제 해결을 통해 **논리적 사고력과 문제 해결 능력을 기르는 알고리즘 동아리**입니다.

단순히 정답을 맞히는 것을 넘어, 다양한 접근 방식을 고민하고 서로의 풀이를 공유하며 성장하는 것을 목표로 합니다.

---

## 📚 스터디 소개

| 항목 | 내용 |
|---|---|
| 동아리명 | 모코숲 |
| 활동 인원 | 6명 |
| 활동 기간 | 2026.4 ~ 2026.12 |
| 정기 모임 | 매주 화요일 18:00 ~ 21:00 |
| 활동 분야 | 자료구조 및 알고리즘 |
| 사용 언어 | Java, Python, c++, Kotlin |
| 주요 활동 | 알고리즘 문제 풀이 및 풀이 리뷰 |

<br>

## 🎯 활동 목표

- 꾸준한 문제 풀이를 통한 알고리즘 역량 향상
- 문제에 대한 다양한 접근 방식 학습
- 시간 및 공간 복잡도를 고려한 효율적인 문제 해결
- 풀이 과정과 아이디어를 논리적으로 설명하는 능력 향상
- 구성원 간 지식 공유 및 상호 성장

<br>

## 🔄 스터디 진행 방식

### 1. 문제 선정 및 풀이

매주 각자 1~2문제를 선정하여 해결합니다. <br>
문제 해결 후 작성한 풀이 코드를 GitHub에 업로드합니다.

### 2. 풀이 공유 및 질문

각자 선정한 문제를 소개하고, 문제에 접근한 방식과 해결 과정을 설명합니다. <br>
풀이 과정에서 어려웠던 부분이나 고민했던 내용을 공유하고 자유롭게 질문합니다.

### 3. 상호 피드백

서로의 풀이를 살펴보며 좋았던 부분과 개선할 수 있는 부분을 논의합니다. <br>
다양한 접근 방식과 구현 방법을 비교하며 더 효율적인 해결 방법을 고민합니다.

<br>

## 📝 활동 기록

매주 진행한 알고리즘 문제와 구성원별 풀이 코드를 기록합니다.

주차별 문제 목록과 활동 내역은 [📋 스터디 활동 기록](./docs/log.md)에서 확인할 수 있습니다.

### 📂 디렉터리 구조

```text
📦 algoitzy/
├── 📂 assets/
│   └── logo.png
├── 📂 problem/
│   ├── 📂 0월 0주차/
│   │   ├── 📂 이름/
│   │   │   └── 📂 문제명/
│   │   │       └── 풀이 코드
│   │   └── 📂 이름/
│   │       └── 📂 문제명/
│   │           └── 풀이 코드
│   └── 📂 0월 0주차/
│       └── ...
├── 📂 docs/
│   └── log.md
└── README.md
```

**디렉터리 관리 기준:** `주차 → 구성원 → 문제 → 풀이 코드`

| 경로 | 설명 |
|---|---|
| `assets/` | 동아리 로고 및 이미지 |
| `problem/` | 알고리즘 문제 풀이 코드 |
| `problem/0월 0주차/` | 주차별 문제 풀이 |
| `problem/0월 0주차/이름/` | 구성원별 풀이 코드 |
| `problem/0월 0주차/이름/문제명/` | 문제별 풀이 코드 |
| `docs/log.md` | 주차별 문제 목록 및 활동 기록 |
