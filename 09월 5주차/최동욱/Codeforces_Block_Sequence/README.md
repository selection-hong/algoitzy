# [Codeforces Block Sequence 문제 링크](https://codeforces.com/problemset/problem/1881/E)

## E. Block Sequence

길이가 n인 정수 수열 a가 주어진다.

수열이 여러 개의 블록으로 이루어져 있고, 각 블록이 자신의 길이로 시작한다면 그 수열을 아름다운 수열이라고 한다. 즉, 각 블록에서는 먼저 블록의 길이가 나오고, 그 뒤에 해당 블록의 원소들이 나온다.

예를 들어, 수열 [3, 3, 4, 5, 2, 6, 1]과 [1, 8, 4, 5, 2, 6, 1]은 아름다운 수열이다(서로 다른 블록은 다른 색으로 표시되어 있다). 반면 [1], [1, 4, 3], [3, 2, 1]은 아름다운 수열이 아니다.

한 번의 연산으로 수열에서 임의의 원소 하나를 제거할 수 있다. 주어진 수열을 아름다운 수열로 만들기 위해 필요한 최소 연산 횟수를 구하여라.

입력
첫 번째 줄에 테스트 케이스의 개수 t (1 ≤ t ≤ 10^4)가 주어진다. 이후 각 테스트 케이스에 대한 설명이 이어진다.

각 테스트 케이스의 첫 번째 줄에는 수열 a의 길이 n (1 ≤ n ≤ 2·10^5)이 주어진다.

두 번째 줄에는 n개의 정수 a1, a2, …, an (1 ≤ ai ≤ 10^6)이 주어진다.

모든 테스트 케이스에 대한 n의 합은 2·10^5을 넘지 않는다.

출력
각 테스트 케이스마다 수열 a를 아름다운 수열로 만들기 위해 필요한 최소 삭제 횟수를 한 줄에 하나씩 출력한다.
