# C. XOR 최대화, 연산 횟수 최소화

**원제:** Maximize XOR, Minimize Operations  
**시간 제한:** 테스트당 2초  
**메모리 제한:** 테스트당 512MB  
**입출력:** 표준 입력 / 표준 출력

## 문제

음이 아닌 두 정수 $x$, $y$가 주어집니다. 다음 연산을 원하는 횟수만큼 수행할 수 있습니다.

$$
(x, y) \rightarrow (x - 1, y + 1)
$$

단, $x = 0$일 때는 연산할 수 없으며, 연산을 한 번도 수행하지 않아도 됩니다.

목표는 연산 후의 $x \oplus y$를 최대화하는 것입니다. 여기서 $\oplus$는 비트 단위 XOR 연산을 뜻합니다. 최댓값을 만드는 방법이 여러 가지라면, 그중 연산 횟수가 가장 적은 방법을 선택합니다.

각 테스트 케이스에서 **얻을 수 있는 XOR의 최댓값**과 **그 최댓값을 얻는 데 필요한 최소 연산 횟수**를 구하세요.

## 입력

첫째 줄에 테스트 케이스의 수 $t$가 주어집니다.

$$
1 \le t \le 10^4
$$

이후 $t$개의 줄에 각 테스트 케이스의 초기값인 두 정수 $x$, $y$가 주어집니다.

$$
0 \le x, y < 2^{29}
$$

## 출력

각 테스트 케이스마다 XOR의 최댓값과 이를 얻기 위한 최소 연산 횟수를 공백으로 구분하여 한 줄에 출력합니다.

## 예제 입력

```text
3
3 1
0 5
6 4
```

## 예제 출력

```text
4 3
5 0
10 4
```
